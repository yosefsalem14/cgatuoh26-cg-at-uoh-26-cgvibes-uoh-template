Build and Run
Open the folder HW3/out/build/x64-Debug and copy cube.obj, cube2.obj, diamond.obj, pyramid.obj to it.

Run the program.

General Settings:

"UI Shift"	Leave OFF.
"Invert Colors"	Leave OFF.
"Show 2D Drawings"	Leave OFF.

Keyboard Shortcuts:
1, 2, 3	Switch background pattern mode.
+	Increase background intensity.
-	Decrease background intensity.
r	Reset intensity to 1.0.

3D Model Controls:	
w / s	Move model up/down (Local Translation Y).
a / d	Move model left/right (Local Translation X).
q / e	Move model forward/backward (Local Translation Z).
z / x	Rotate model around X axis.
c / v	Rotate model around Y axis.
b / n	Rotate model around Z axis.
R	Reset all transformations.

Mouse Controls:

Left-click drag (outside UI)	Rotate the model.
Right-click drag (outside UI)	Translate the model.
Middle-click drag (scroll wheel)	Scale the model (zoom).
