
Setting
"UI Shift"	Leave ON only for Part 4; otherwise OFF (to avoid weird clicks).
"Invert Colors"	Leave OFF for all tests (otherwise colours are reversed).
"Show Triangle Fill"	Not applicable for this assignment – ignore.

Keyboard Shortcuts

1, 2, 3	Switch background pattern mode (0, 1, 2 – see Part 1).
+	Increase background intensity.
-	Decrease background intensity.
r	Reset intensity to 1.0.
Mouse Controls (Line Drawing)

Click and drag (left mouse) outside UI	Draw a line from start to end point (or circle if Circle Mode is ON).
Click inside UI	Interacts with UI widgets (buttons, sliders, etc.).
